API Endpoint
POST /process/csv
Process CSV/Excel files with comprehensive transformation pipeline including parsing, cleaning, filtering, aggregation, and export.
Request Formats
Multipart Form-Data
Content-Type: multipart/form-data Fields: - file: Binary file - url: Remote file URL - raw_csv: Raw CSV text - output_format: json|csv|excel - provide_download: true|false
JSON Body
{ "url": "https://example.com/data.csv", "parsing": { "delimiter": ",", "has_header": true }, "cleaning": { "drop_duplicates_rows": true, "auto_convert_types": true }, "selection": { "columns": ["col1"], "filters": [{ "column": "age", "op": ">", "value": "25" }] }, "aggregation": { "by": ["category"], "metrics": { "amount": ["sum", "mean"] } }, "export": { "output_format": "json" } }
Filter Operators
= > >= < <= != contains regex
Aggregation Functions
sum mean median std count nunique
Response Format
{ "data": [...], "download_url": "/downloads/file.csv", "stats": { "rows": 1000, "columns": 5, "numeric_columns": [...] }, "errors": [] }
cURL Examples
# Upload file curl -X POST /process/csv \ -F "file=@data.csv" \ -F "output_format=json" # From URL with filters curl -X POST /process/csv \ -H "Content-Type: application/json" \ -d '{ "url": "https://example.com/data.csv", "selection": { "filters": [{ "column": "age", "op": ">", "value": "25" }] } }'
Processing Pipeline
1. Parse CSV/Excel
2. Clean data
3. Convert types
4. Filter rows/columns
5. Aggregate metrics
6. Sort results
7. Export format
